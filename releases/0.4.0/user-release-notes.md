# Schmegettes 0.4.0

## Game options
- **Difficulty.** Hosts can choose **Any**, **Easy**, **Medium** or **Hard** in game options (⚙). Any is the default and plays just as before. With a level chosen, the board is built from categories at that level first, then the nearest level, so you still never run short of fresh categories. Each category's level is set once and stays put.

## Lobby
- **The TV shows the address to join at**: "Join at schmegettes.app/join".
- **A cleaner player tab**: the folded player list no longer has a "Players" label.
