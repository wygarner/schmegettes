# Schmegettes 0.5.0

## Stats and leaderboard
- **Your stats.** Signed-in players have a new **Stats** page, linked from Home, with your all-time results across finished games.
- **Leaderboard.** See how you rank against other players. Your own row stays pinned so you can always find it.
- **Stay off it if you like.** You're on the leaderboard by default. Turn off the switch in **Account** to hide yourself; your own stats still work.
- Guests don't have stats; sign in to start counting.
