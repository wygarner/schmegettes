# Schmegettes 0.3.0

## Lobby
- **More room for the code.** The player list is folded into a slim tab on the right; tap it to see who's in. It flashes when someone joins.
- **Simpler buttons**: **Join** and **Leave**, and small 🔊 (narrator voice) and ⚙ (game options) icons.
- **No more timer setting.** Every game gives 9 seconds to buzz in and 9 seconds to answer.
- **Norman is the new default narrator.** If you never picked a voice, your host device downloads Norman once before your next game. If you picked Kristin or John, you keep them.
- **Your buzzer appears when the game starts**, if you're hosting and playing.

## Playing
- **Quick picks** (a new game option, off unless the host turns it on): say just a category, like "Opera", and you get the lowest clue left in it.
- **A buzz on the TV** when someone buzzes in, so the whole room knows.
- **The category card stays up a little longer** after a pick, so everyone can read it.
- **The narrator reads every clue.** Fixed: some clues, especially long ones, were skipped in silence.
