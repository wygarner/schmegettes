# Schmegettes 0.7.0

## Knowing what's going on
- **Notices from us.** If something's broken, maintenance is coming up, or there's something new, you'll see it in a banner at the top of Home. More than one? Tap **+1 more** to see them all. Dismiss one and it stays gone on that device, unless we update it.
- **Before you press Start.** Hosts see incidents and any maintenance starting within two hours right in the lobby, so a game night doesn't get cut off. Nothing ever pops up during a game.
- **"Is it me or them?"** If Home can't reach Schmegettes, it tells you, with a link to our status page. If your own device is offline, it says that instead.

## Behind the scenes
- **We hear about problems first.** Schmegettes now tells us when something breaks, often before anyone notices.
- **One room's trouble stays in that room.** If something goes wrong in one game, other games carry on. Reconnecting picks the game up where it stopped.
